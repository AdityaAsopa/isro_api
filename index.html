Quick start

Fetch all active spacecraft in GEO orbit
fetch('https://isro.vercel.app/api/spacecrafts?status=active&orbit_type=GEO')
  .then(r => r.json())
  .then(data => console.log(data.spacecrafts))
Get Chandrayaan-3 mission details
fetch('https://isro.vercel.app/api/spacecraft_missions/64')
  .then(r => r.json())
  .then(mission => console.log(mission.orbit_type, mission.mass_kg))
All PSLV launches
fetch('https://isro.vercel.app/api/launchers?vehicle_family=PSLV')
  .then(r => r.json())
  .then(data => console.log(`${data.launchers.length} PSLV variants`))
